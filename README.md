# UltraMonitor

![Java](https://img.shields.io/badge/Java-21%2B-blue) ![JavaFX](https://img.shields.io/badge/JavaFX-25-orange) ![License](https://img.shields.io/badge/License-AGPLv3-red)

**Портативная десктопная утилита для мониторинга датчиков железа и стресс-тестирования системы.**

UltraMonitor показывает в реальном времени показания процессора, памяти, дисков и сети,
а также умеет нагружать систему тестами CPU / RAM / диск / GPU, чтобы проверить её
стабильность и охлаждение. Написана на **Java 21+** (собрана на Java 25), **JavaFX** и
**OSHI** — без установки, один jar + лаунчер.

---

## Возможности

- **Главное меню** — переключатели открывают окна «Датчики» и «Стресс-тест», которые
  можно держать открытыми рядом, наблюдая за датчиками во время нагрузки.
- **Окно датчиков, две вкладки:**
  - *Sensors* — каждый датчик, найденный OSHI, в виде живой таблицы
    `Current | Min | Avg | Max`:
    - температура, загрузка, частота и напряжение CPU;
    - загрузка и частота каждого ядра;
    - использование RAM и swap;
    - занятость дисков + скорость чтения/записи по каждому диску;
    - скорость загрузки/выгрузки по сети;
    - уровень заряда, напряжение и оставшееся время батареи (на ноутбуках);
    - обороты вентиляторов (если поддерживаются ОС).
  - *System Info* — полная инвентаризация железа, сгруппированная по разделам
    (ОС, CPU, память, материнская плата, BIOS, графика, диски, файловые системы,
    сеть, батарея, дисплеи, USB, звук); живые значения подсвечиваются синим.
- **Настраиваемая частота обновления** — от **1 до 10 000 мс**; сохраняется в
  `config.json` рядом с приложением.
- **Стресс-тест** — четыре теста со своими параметрами:
  - *CPU* — полная нагрузка с плавающей точкой на выбранных ядрах (слайдер потоков);
  - *RAM* — выделение и постоянная запись/чтение буферов (слайдер % доступной памяти);
  - *Disk* — последовательная запись и чтение временного файла (слайдер размера, МБ);
  - *GPU* — нагрузка на конвейер отрисовки.
  - Опциональная длительность в секундах (пустое поле = до остановки вручную;
    максимум 86 400 с), кнопки **Start / Stop**, живые индикаторы загрузки CPU,
    RAM и температуры, прогресс-бар и **автоматическая остановка при 90 °C**.
- **Тёмный UI** — кастомные окна без рамки, анимированные переключатели и живой
  индикатор «LIVE».
- **Портативность** — один jar + лаунчер, без установки.
- **Headless self-test** для CI / смоук-тестов: `java -jar UltraMonitor.jar --selftest`.

> Примечание: на Windows температура CPU и обороты вентиляторов требуют драйвера,
> например [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor)
> (или прав администратора с OpenHardwareMonitor). Без него эти датчики показывают «—».

## Требования

- **Java 21 или новее** (собрано и протестировано на Java 25).

## Сборка

```bat
build.bat
```

Скрипт собирает проект и кладёт портативную сборку в `dist/`:

```
dist\
├── UltraMonitor.jar
└── launch.bat
```

Также можно собрать вручную через Gradle:

```bat
gradlew.bat clean fatJar
```

## Запуск

```bat
dist\launch.bat
```

Или из терминала:

```bat
java -jar dist\UltraMonitor.jar
```

Во время разработки:

```bat
gradlew.bat run
```

## Self-test (CI / смоук-тесты)

```bat
java -jar UltraMonitor.jar --selftest
```

Режим без GUI: опрашивает датчики, печатает список показаний и системную информацию,
завершается с кодом `0` при успехе и `1` при ошибке.

## Конфигурация

`config.json` хранится рядом с jar (при запуске из каталога сборки — в `~/.ultramonitor`):

```json
{ "refreshIntervalMs": 1000 }
```

- `refreshIntervalMs` — интервал обновления датчиков в миллисекундах (1–10 000).

## Структура проекта

```
src/main/java/com/ultramonitor/
├── Main.java              точка входа (GUI + --selftest)
├── GuiApp.java            JavaFX-приложение: меню + окна датчиков и стресс-теста
├── config/AppConfig.java  портативная персистентность config.json
├── monitoring/            слой абстракции над железом (OSHI)
│   ├── MetricsCollector   интерфейс, общий для GUI и CLI
│   ├── OshiMetricsProvider реализация на OSHI
│   ├── SensorReading      одно показание датчика
│   ├── SensorStats        аккумулятор min/avg/max
│   ├── LiveStats          статистика сессии по всем датчикам
│   ├── SensorRow          строка таблицы для отображения
│   ├── InfoEntry          строка «ключ/значение» System Info
│   └── Format             форматирование единиц и времени
├── stress/                движок стресс-тестов
│   ├── StressTest         интерфейс теста
│   ├── StressRunner       запуск/остановка набора тестов
│   ├── CpuStress          нагрузка на CPU
│   ├── MemoryStress       нагрузка на RAM
│   ├── DiskStress         нагрузка на диск
│   └── GpuStress          нагрузка на GPU
└── ui/                    JavaFX-вью, переключатель, тайтл-бар, тема
```

Юнит-тесты — в `src/test/java/com/ultramonitor/`.
